# Instruções para Exclusão de Dados

**Taby** ("o Aplicativo") armazena todos os dados do usuário localmente no seu dispositivo. Nenhum dado é armazenado em servidores externos.

## Como excluir seus dados

Se você deseja remover seus dados, basta **excluir o aplicativo** do seu dispositivo. Isso removerá permanentemente todas as notas, abas, imagens, vídeos e configurações associadas ao Aplicativo.
