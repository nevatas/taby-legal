# Instructions de suppression des données

**Taby** (« l'Application ») stocke toutes les données utilisateur localement sur votre appareil. Aucune donnée n'est stockée sur des serveurs externes.

## Comment supprimer vos données

Si vous souhaitez supprimer vos données, il vous suffit de **supprimer l'application** de votre appareil. Cela supprimera définitivement toutes les notes, onglets, images, vidéos et paramètres associés à l'Application.
