# Anleitung zur Datenlöschung

**Taby** („die App") speichert alle Nutzerdaten lokal auf Ihrem Gerät. Es werden keine Daten auf externen Servern gespeichert.

## So löschen Sie Ihre Daten

Wenn Sie Ihre Daten entfernen möchten, **löschen Sie einfach die App** von Ihrem Gerät. Dadurch werden alle mit der App verbundenen Notizen, Tabs, Bilder, Videos und Einstellungen dauerhaft entfernt.
